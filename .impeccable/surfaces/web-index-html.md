# Site web de réservation (web/index.html)

Mode : Persuade. Aperçu visuel du site de réservation, dans l'univers de l'application
(« Bleu pastel du Lauragais »). Public : le voyageur aéroport / gare. Action : saisir départ,
arrivée, date et heure, voir une estimation, réserver Fabrice. Preuves : vraies photos des deux
véhicules et de Fabrice, grille tarifaire réelle, règles d'attente et d'annulation des CGV.
La logique d'envoi n'est pas branchée (aperçu) ; l'estimation est à vol d'oiseau et étiquetée.

d'indigo. Refuse le héros photo + rangée de cartes des sites VTC.

marques rond / carré pour départ / arrivée.
